📸 Instagram Clone

A responsive Instagram Clone built using HTML, CSS, and JavaScript. This project recreates the basic Instagram interface with features like stories, posts, suggested accounts, notifications, and a new-post section.

📌 Project Overview

This Instagram Clone is a frontend web project created to practice HTML structure, CSS styling, responsive design, and JavaScript functionality.

The project provides an Instagram-like user interface where users can view stories, create new posts, check suggested accounts, and interact with different UI elements.
